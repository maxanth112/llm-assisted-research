## Notes

- Primary estimand: paired marginal contrast D|E=1 averaged over T = 0.5*[(Y_101-Y_100)+(Y_111-Y_110)]
- Primary test: one-sample paired t-test on item-level contrast values
- Paired bootstrap CI: frozen-seed, item-clustered, 10,000 resamples
- Robustness: effect-coded binomial GEE with item-clustered robust SE (secondary, not gated)
- McNemar tests are secondary paired checks (genuinely binary, not averaged)
- Model is a FIXED effect -> power is per-model; no generalization claim
- MDE depends on (N, k, sigma, p0) -- no single fixed MDE is claimed
- MC SE = sqrt(power*(1-power)/n_sims); MC CI = power +/- 1.96*MC_SE

## Per-Model Power (model is a fixed effect)

Each model has its own baseline accuracy p0 on adversarial regimes.
Power is computed separately because the paired marginal contrast variance
depends on p0. These are pre-specified operating points.
