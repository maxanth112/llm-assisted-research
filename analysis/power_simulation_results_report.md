# Model-Inference Power Simulation Results

## Design

- **Conditions:** 5-condition (000,100,110,101,111)
- **Primary estimand:** D|E=1 averaged over T, adversarial regimes
- **Primary test:** Wald z-test on paired marginal contrast
- **Secondary:** McNemar 101v100, McNemar 111v110, Enumeration 100v000, T|E=1
- **Alpha:** 0.05
- **N simulations:** 500 per configuration
- **Delta T (trajectory effect):** 0.0
- **Delta TD (interaction):** 0.0

## Notes

- Primary estimand: D|E=1 averaged over T = 0.5*[(Y_101-Y_100)+(Y_111-Y_110)]
- Effect coding (T_eff=T-0.5, D_eff=D-0.5) ensures D coefficient is averaged over T
- McNemar tests are secondary paired checks (genuinely binary, not averaged)
- Model is a FIXED effect → power is per-model; no generalization claim
- MDE depends on (N, k, σ, p₀) — no single fixed MDE is claimed

## Per-Model Power (model is a fixed effect)

Power is computed separately because the marginal contrast variance
depends on p0.  These are pre-specified operating points.
