## Notes

- Primary estimand: paired marginal contrast D|E=1 averaged over T = 0.5*[(Y_101-Y_100)+(Y_111-Y_110)]
- Primary test: one-sample paired t-test on item-level contrast values
- Robustness: effect-coded binomial GEE with item-clustered robust SE (secondary, not gated)
- McNemar tests are secondary paired checks (genuinely binary, not averaged)
- Model is a FIXED effect → power is per-model; no generalization claim
- MDE depends on (N, k, σ, p₀) — no single fixed MDE is claimed
